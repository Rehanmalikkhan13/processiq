# ProcessIQ

### AI-Powered Manufacturing Process Planning & Optimization

ProcessIQ is an AI-powered manufacturing planning assistant designed
to generate, validate, and optimize Bill of Process (BoP) sequences
based on product requirements, manufacturing resources, and
production constraints.

## Problem Statement

SISTEC Hackathon — IA-10
Industry Automation / Smart Manufacturing

## Core Concept

ProcessIQ combines AI-assisted process planning with deterministic
validation and optimization.

## Core Flow

Product Requirements
        ↓
AI Requirement Analysis
        ↓
Candidate BoP Generation
        ↓
Constraint Validation
        ↓
Process Optimization
        ↓
Human Review
        ↓
Approved BoP

## Project Structure

- `frontend/` — Web application
- `backend/` — Backend API
- `ai/` — AI planning and optimization
- `data/` — Manufacturing knowledge and constraints
- `docs/` — Project documentation
- `tests/` — Tests
- `scripts/` — Development utilities
